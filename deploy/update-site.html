这个目录里要放什么

文件谁用说明
version.json插件(机器读) 清单:版本号 + zip 地址 + sha256 + 说明。必须有,且必须带 sha256(没校验和插件会拒绝安装)。
dsh-grsai-canvas-vX.Y.Z.zip插件(机器下) 打包好的插件包(Compress-Archive -Path dsh-grsai-canvas -DestinationPath …)。
index.html人看 本页。放进来就能当发布页/下载页;不放也不影响插件更新。

三个文件放同一个目录即可,目录随便叫什么(例如 /grsai/)。 插件只要求两件事:① 清单地址能 GET 到 JSON;② zip 能 GET 到(不需要登录)。 任意静态站 / 对象存储 / GitHub Releases 都行。

想留旧版本:把旧 zip 也留在同一目录(或子目录),把当时的 version.json 另存成 version-0.3.4.json 备查;插件本地的「回滚上一版」用的是它自己更新前的备份,不依赖这里。

  • 在本页所在目录也放一份 version.json(或直接把本页传到同一目录);
  • 刷新本页,顶部「当前发布」就会显示新版本;插件里点「检查更新」也能看到。

与命令行等价:powershell -ExecutionPolicy Bypass -File deploy\make-update-manifest.ps1 -Zip <zip> -Relative -NotesFile notes.txt
(-Relative = 清单里只写 zip 文件名,插件按清单地址自己拼;要写死绝对地址就把它换成 -Base https://站点/目录)
两边算出来的 sha256 是同一个值,随便用哪个。
