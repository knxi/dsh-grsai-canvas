# 页面清单 · 画布 UI 重构(D 期布局骨架)· v0.1

> 依据:DeepSeek开发任务书-画布功能增强.md §6.2 目标信息架构;skill:design-ui-prototype 页面清单模板。
> 宿主约束:画布 UI 挂载于 DSH 右侧栏 tab pane(slots: sidebar.right.pane.tab),非独立页面;pane 宽度有限(桌面约 380–520px,可 popOut 弹出更大)。

## 1. 目标与非目标

| 项 | 内容 |
|---|---|
| productGoal | 把「导入→选图→写提示词→调模型尺寸→生成→看结果」做成 pane 内直达主工作流;非生成功能退出生成区;每分区职责单一 |
| nonGoals | 不做节点编辑器;不换 UI 框架(仍用 h 虚拟 DOM + S 样式);不加营销首页;不做组树/PS 引擎/分页 |

## 2. 用户

| 角色 | 任务 | 权限范围 |
|---|---|---|
| DSH 用户(默认单用户) | 画布改图/生成图/加字/导出/放大/分层 | 本机全部,无权限区分 |

## 4. 分区清单(同一「页面」= 画布 pane,按信息架构分区)

数组顺序=用户决策顺序。每区主要操作恰好一个。

### 4.1 顶部紧凑导航(新增,替代现 21-topright 大杂烩)
- 主要操作:**导入图片**(＋图片,含粘贴/拖入入口不变)
- 次级:资源工作区(开停靠区 workspace)/图层(开停靠区 layers)/生成记录(开停靠区 history)/模板 Skills(开停靠区 skills)/设置与更多(⚙ 弹层)
- 移除入顶栏:适应/100%/±缩放(→4.3 画布视图控制)、🔑分层·未配、⬆放大(→⚙ 更多,非核心缺失不常驻警告)、popOut(→⚙ 更多)

### 4.2 左侧工具栏(保留 20-toolbar,按当前工具显隐颜色/粗细)
- 工具 8 键(选择/平移/箭头/矩形/自由画笔/蒙版/橡皮/裁剪,以 TOOLS 实际为准)+ 撤销/重做/清空标注 + 图层顺序 4 键(迁入评估:或随停靠区 layers 面板)+ 颜色块/粗细滑杆(仅标注类工具时显示)

### 4.3 画布视图控制(新增小块:集中缩放/适应/100%)
- 位置:画布右下(生成卡上方)或左下状态栏旁;适应(0)/100%(1)/－/＋/缩放百分比展示
- 适应视口只统计可见图(全隐藏安全回退,任务书 C 期规则)

### 4.4 生成区(右下主卡,仅当前生成)
- 输入摘要行(主图/参考图数/蒙版数,紧凑)、提示词 textarea、模型/尺寸行、主按钮(生成/停止两态,按上下文命名:生成新图/按标注改图/跨平台出图 N 张)、简短进度(阶段+进度条)
- 「停止轮询」≠「上游已取消」文案区分

### 4.5 生成高级选项(生成区内按需展开)
- 质量/背景/裁剪(只提交标注范围)/附加说明/跨平台批量尺寸;收起不重置参数;展开时紧凑摘要(参考图数/批量张数)始终可见

### 4.6 选中对象属性区(选中图片/文字/标注时出现在生成区上方)
- 图片:名称/尺寸/参考标记/显隐/锁定(A 期接);图片操作行(复制/存工作区/下载/导出底图与文字/删除)自 gen-card 迁入;对齐分布条(multi≥2)
- 文字:文字属性整块自 gen-card 迁入(字体/字号/描边/颜色/导入字体);「分层」须标注「导出底图与文字」非 AI 拆层
- 无选中时不渲染(不留灰色占位)

### 4.7 资源停靠区(受控互斥:history/layers/workspace/skills 四标签)
- 生成记录(A 期主战场)/图层管理(C 期)/工作区图片(现 29-workspace-panel)/模板 Skills(现 26-skills-panel,Agent 动作保留并分区)
- 位置:右侧或左侧抽屉,与画布共存,可收起;对比视图(B 期)用专门视图不走停靠区

### 4.8 设置与更多(⚙ 弹层,保持 27-settings-panel 职责)
- API 配置/Agent 超分状态/更新/低频维护(清空画布、保存画布迁此,破坏性操作远离生成主按钮);分层密钥🔑/放大⬆入口收编于此(保留独立面板内容)

## 6. 验收口径(引用任务书)

- 同视口截图前后对比 + 默认可见操作数量下降;主工作流六步直达;默认不展开文字编辑器/分层配置/超分安装/模板管理/批量选项;一个受控辅助面板;所有保留按钮有实际动作;1200×900/390×700/360×640/640×420 四视口可达。
