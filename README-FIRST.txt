========================================
 dsh-grsai-canvas  ——  DSH 画布插件（grsai 改图）
========================================

【装到这台电脑：3 步】

 1. 双击本目录里的            install.cmd
    （已经替你写好参数，直接双击即可；窗口里出现 [ok] 就是装好了）

 2. 重启 DSH
    关掉 DSH 的窗口，再重新启动一次（插件要在重启后才加载）。
    如果 DSH 从来没在这台电脑上跑过也没关系，安装脚本会自己把它的
    profile 初始化出来。

 3. 打开画布 → 填 APIKEY
    重启后侧栏左下角会出现「画布」按钮（右侧栏引导页里也有）。
    点开它：右上角那个按钮这时写着「填 APIKEY」，点它会弹出设置面板（第一次打开
    画布时它自己就会弹出来）。面板里两格：
       ① GrsAI APIKEY  ← 粘 grsai.com 后台的 KEY
       ② 接口地址      ← 默认 https://grsai.dakka.com.cn，一般不用改；
                          用中转/自建兼容服务时才改（只填域名，后面路径插件自己拼）
    点「保存设置」即可。两项都只存在本机浏览器里。

【怎么用】

 · 加图：画布右上「＋图片」选文件 / 把图拖进来 / Ctrl+V 粘贴 /
   点「工作区」从当前目录挑。
 · 选一张图 → 用左侧工具在图上标注（画笔 / 箭头 / 矩形 / 椭圆 / 文字 / 橡皮，
   快捷键 V B A R O T E，Ctrl+Z 撤销）。
 · 写提示词 → 点「按标注改图」。结果会自动放在原图右边，方便对比着继续改。
 · 常用套路点右上角「Skills」：证件照 / 抠图 / 换背景 / 去水印 / 高清修复…
   选中才生效，不选就是普通改图；面板下半部分可以自己加模板（存到工作区）。
 · 画布自动保存到 <工作区>\画布\state.json，刷新、重开都在。
 · 「尺寸」这一栏：不同模型认的写法不一样（gpt-image-2 系要 1024x1024 这种
   像素值，nano-banana 系要 3:4 这种比例）。点开「尺寸」框，里面列的就是当前
   模型支持的值；填错了框下面会出黄字提醒，提交时也会自动换算成能用的值。
 · 换模型：点模型框右边的 ▾，菜单里列全了型号（后面标着它认像素值还是比例）。
 · 尺寸默认「原图比例」：上传什么比例的图就按什么比例出图，换张图会自动跟着变。
 · 更新插件（如果有人给了你更新地址）：设置 →「③ 插件更新」→ 粘上清单地址 →
   点「检查更新」→「立即更新」。更新完刷新页面；宿主半边要重启 DSH 才换。
   更新坏了可以点「回滚上一版」（每次更新都会自动备份）。

【图片分层（交给 Agent）】

  · 这条链路和 GrsAI 那把 key 不是一回事：走的是 APIMart 的 Seedream 图层分解
    （一次返回底图 + 每层带透明通道的 PNG），再由本地技能组装成可编辑 PSD。
  · 技能（image-layering）随插件自带：装插件时会自动铺到
        <DSH home>\skills\image-layering
    以后更新插件，宿主半边启动时也会自动补齐 / 升级技能；升级前旧技能整份备份到
        <DSH home>\skills\.backup\
    你填好的接口地址与密钥（技能里的 config\*.json）永远不会被覆盖。
  · 接口和密钥在画布右上角那颗「🔑 分层」里填（默认地址 https://api.apimart.ai，
    只填域名、别带 /v1）。还没配好时这颗按钮是橙色的「🔑 分层·未配」。
  · 技能是 Python 写的，要先有 Python 3 和这几个包：
        pillow psd-tools opencv-python numpy svglib reportlab
    一条命令装齐：
        python -m pip install -r <DSH home>\skills\image-layering\requirements.txt

 ★ 关键：箭头只能告诉模型“改哪里”，说不清“改成什么”。
   最有效的做法是用【文字工具 T】在图上写一句「改成深夜食堂」，
   或者在提示词框里写一句 —— 插件会把这些话原样交给模型。

【卸载】

 双击本目录里的 uninstall.cmd，然后重启 DSH。

【出问题先看这里】

 · 看不到「画布」按钮 → 确认第 2 步重启做了，再按 Ctrl+R 刷新页面。
 · 自检地址 http://127.0.0.1:3080/grsai-canvas/ping
   应该返回 JSON，里面有 "version" 和当前工作区根。
 · 上游到底回了什么 → http://127.0.0.1:3080/grsai-canvas/debug
   （最近 40 条上游返回；创建任务后一直不出图时先看这个）
 · 任务不会白做：万一中途关了页面 / 切了标签，重开画布会自动接着查，
   拿到图就补到原图旁边。
 · 提示 apikey error → KEY 不对或没额度。
 · 提示 Failed to fetch → 通常是图太大或 DSH 服务刚重启，稍等重试；
   插件会把提交图自动缩到长边 2048，按钮边上会显示实际提交尺寸。
